# 口播脚本

## 1. 字数

实测：edge-tts 云希（zh-CN-YunxiNeural）用默认语速时，**每分钟约 235 个字**（不算标点）。两支样片的数据是 470 字 122 秒、596 字 152 秒。加上句间停顿和纯画面的时间，成片大约是纯口播时长的 1.25–1.35 倍。所以：

**目标字数（不算标点）≈ 时长（分钟）× 235 ÷ 1.3 ≈ 时长 × 180**

| 时长 | 口播字数（不算标点） |
|---|---|
| 60 秒 | 约 180 |
| 90 秒 | 约 270 |
| 3 分钟 | 约 540 |
| 4 分钟 | 约 720 |
| 5 分钟 | 约 900 |

换别的音色或别的 TTS，先生成三五句量一下实际语速，再按同样的方法算。

配音生成后，以 `timeline.json` 里的实际总时长为准。超出要求 10% 以上就删句子，不要靠加快语速来压时长。

## 2. 先写问题、主线和回答

动笔之前写三句话，之后也写进分镜的 `meta`（见 `directing.md` 第 1 节）：
- **问题**：观众真想知道答案的那一个问题；
- **主线**：从问题走到回答的推理链，每一环都由上一环引出，不是章节标题的列表；
- **回答**：结尾要说的那句话，包括证据能支持到哪一步。

写完的每一段都要能挂在主线的某一环上，挂不上的删掉。用户要“更丰富”时，先找主线上缺的环节（例子、步骤、对比、条件、取舍、反例、后果），不要先加图。

## 3. 结构

| 段落 | 占比 | 要做到 |
|---|---|---|
| 钩子 | 前 5–8% | 第一句话就是问题本身或一个反常识的画面。不说“大家好”，不说“今天我们来聊聊”。 |
| 承诺 | 1–2 句 | 告诉观众看完能明白什么。 |
| 主体 | 80% | 按题型的叙事骨架（见 `routing.md`）展开。每段都按 **问题 → 直觉 → 机制或证据 → 回到主问题** 来写。 |
| 边界 | 5% | 还不知道的、有争议的、我们估算的部分。 |
| 收束 | 5% | 回答开头的问题，留一句观众能复述的话。 |

传播用的竖版剪辑：前 3 秒必须出现最强的画面和问题；全长控制在 60–90 秒；只讲主体里最好的 1–2 段。

## 4. 句子规则

- **口语、短句。** 每句不超过 25 字，适合一行字幕。长句拆开，不用书面连接词，比如“此外”“与此同时”“综上所述”。
- **数字要转成能感受的说法。** 先给类比，再给数字，比如“比一根头发还细，大约 30 微米”。数字四舍五入到观众能记住的精度。
- **一句只讲一件事**，并且要能对应一个画面。写的时候想着“这句话的时候，屏幕上是什么”。
- **先讲它做了什么，再说它叫什么。** 术语第一次出现时立刻解释，之后统一用同一个词。比如先说“一道闸门，平时卡住齿轮”，再说“这叫擒纵叉”。
- **证据等级要体现在说法里**（见 `research.md` 第 1 节）。宣称就说“他称”，估算就说“如果按……来算”。
- **讲误解的选题**，用“你可能以为……实际上……证据是……”这个句式。
- **讲人物和企业的选题**，讲选择时要讲出“当时还有另一条路”。
- **不要拟人化抽象系统**（比如 AI、黑洞），不要堆形容词，也不要用“震撼”“颠覆”这类词。

## 5. 宣称和估算怎么说（来自 Roadster 样片）

| 等级 | 例句 |
|---|---|
| A 官方或演示 | “倒挂、翻转和加速，是发布会上当众演示过的。” |
| A，但只是官方自己测的 | “特斯拉自己计时零点八一秒。” |
| C 宣称 | “工程师说，推力超过八万牛顿。” |
| C，而且说法冲突 | “工程师说，这股力能达到两千五百公斤，屏幕上显示的数字更高。” |
| E 估算 | “就算二百五十公斤气全部用来悬停，理想情况下也只能撑十秒左右。” |
| 未知 | “量产车多重、电池多大、补满一次气要多久，现在都还没有公布。” |

数字要和 `model.js` 的 `report()` 输出一致，取整到口语的精度（16.7 kN 说成“一万七千牛顿左右”，27.9 kg/s 说成“二三十公斤”）。

## 6. 文件格式（script.md）

`scripts/timeline.py` 和 `scripts/tts_lines.py` 会读这个文件，格式必须一致：

```
# <片名>

## 钩子
[L001] 连光都逃不出来的东西，我们是怎么给它拍照的？
[L002] 答案藏在这一圈光里。{F01}

## 光从哪里来
[L003] 黑洞本身不发光。{F02}
[L004] 亮的，是它周围被加热到极高温度的气体。{F03}
```

格式规则：
- 只有以 `[L数字]` 开头的行才是口播。`#` 标题和空行只起组织作用。
- `{F03}` 是事实编号，生成配音和字幕时会被去掉。
- 一个 `## 小节` 内的句子之间默认停顿 0.25 秒，小节之间停顿 0.6 秒。可以在 `timeline.py` 的参数里调整。
- 需要特殊读音时，在行尾加 `<读作：……>`。TTS 会念尖括号里的内容，字幕仍然显示原文。比如 `[L010] M87* 是…… <读作：M八七星是……>`。

## 7. 写完自查

- [ ] 第一句话就是问题或反常识的画面
- [ ] 字数在目标的 ±10% 以内
- [ ] `brief.md` 里“必须讲清的 3–5 件事”每件都讲了
- [ ] 每个事实句都带 `{F..}`，而且这个编号在事实表里存在
- [ ] 每个数字都和 `model.js` 的 `report()` 输出对得上
- [ ] C、D、E、R 等级的内容，说法里体现了等级
- [ ] 结尾回答了开头的问题，每一段都挂在主线上
- [ ] 大声读一遍：没有拗口的长句，没有连续三句以上的纯数字
