# 需求简报：特斯拉新 Roadster 发布会

- **用户原话**：帮我介绍下马斯克最新特斯拉飞行汽车 Roadster 发布会展示了什么以及设计原理，最终生成便于传播的科普讲解视频
- **受众**：普通观众，没有工程背景；在小红书、抖音、B 站上看
- **时长 / 画幅**：主片约 3 分钟 16:9；另有 60–90 秒 9:16 传播剪辑（用户没说时长，按“便于传播”的推荐）
- **题型**：T2 主（工程原理与传播表达），T9 副（事件：发布会上演示了什么）
- **全片的问题**：发布会上它倒挂、翻身、飞过一排车，是怎么做到的？它真的会飞吗？
- **主线**：发布会演示了什么 → 轮胎的抓地力有上限 → 风扇把车吸向路面，倒挂也能贴住 → 冷气推进器的力不靠轮胎，用来翻身和飞跃 → 气只够喷几秒
- **回答**：倒挂靠风扇吸力，翻身和飞跃靠几秒钟的冷气推力。离持续飞行还很远，推力和气量都还只是工程师的说法。
- **必须讲清的 3–5 件事**：
  1. 发布会实际演示了什么：坡道倒挂、空中翻身落地、飞过一排车、0-60 英里 0.81 秒（特斯拉自己计时）；没有持续飞行，车上没有人。
  2. 风扇吸地：车底气压只比外面低一点，但面积大，大气就把车按向路面；倒挂时这股力要大过车重。
  3. 冷气推进器：向后（向下）喷气，车受到反方向的力，不靠轮胎。
  4. 气量有限：理想情况下也只够喷十秒左右。
  5. 哪些是演示过的，哪些只是宣称。
- **观众看完能说出的一句话**：“倒挂靠吸，翻身靠喷，能喷几秒，离飞行汽车还远。”
- **路线**：固定 R1 剖解（用户在本会话里指定 Roadster 用 anatomy；`references/cases.md` 第 2 节），配纸面风 2D 场景
- **风险**：
  - 时效性：发布会在 3 天前（研究日期：2026-10-18，能联网：是）。合成全片前再核对一次。
  - 争议或证据不足：推力、气量、下压力都是工程师口头说法；下压力有 2,500 kg 和约 4,700 kg 两种说法。
  - 真人、商标、版权：车用中性外观，不画特斯拉标志；不用官方视频画面；不生成马斯克的形象或声音。
- **样片范围**：钩子（发布会演示了什么，提出问题）加一个核心机制：风扇吸地。上一支样片讲过推力测力台，这次不重复。约 40 秒，3 个镜头。
- **复用的母版资产**：跑车剖解模型和侧视贴图直接用 `productions/roadster/scenes/_shared/car` 和 `car_side.png`，开始渲染时再拷进本工程。
