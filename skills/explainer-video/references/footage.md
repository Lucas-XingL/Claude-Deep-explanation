# 开场：先给真实画面，再进入代码动画

## 1. 为什么、什么样

开头先给观众看一个真实的东西：发布会现场、产品照片、档案影像、化石、一段录屏。观众一眼认出“讲的是这个”，注意力就被抓住了；接着进入我们的动画，讲“它是怎么做到的”。真实画面回答“是什么”，代码动画回答“为什么、怎么做到”。

结构（横版 3–6 秒，竖版 2–3 秒）：

```
真实画面（视频或照片，慢慢推近）→ 定格 → 线稿在纸面上扫出来 → 线稿变成我们的模型（同样的位置和大小）→ 进入讲解
```

- 真实视频是一个镜头（`footage.sh` 处理好的 `clip.mp4`）；从定格到模型是另一个镜头（`templates/scene-reveal.html`）。素材只有照片时，一个 reveal 镜头就够了：照片先慢慢推近，再转成线稿和模型。
- 钩子的第一句口播可以压在真实画面上，比如“十月十五号的发布会上，……”。
- 真实画面在屏幕上的整段时间里，左上角都挂着来源署名（“画面：特斯拉官方视频，2026-10-16”）和角标（“官方画面”“资料画面”，或者“AI 还原画面 · 非现场影像”）。
- 模型落下的位置，就是下一个镜头第一帧里主体的位置（匹配剪辑）。

## 2. 每类选题拿什么当真实画面

| 题型 | 真实画面 | 常见来源 |
|---|---|---|
| T1 新品 | 发布会上产品第一次亮相、官方产品图 | 官网、新闻稿资料库、发布会视频 |
| T2 工程原理 | 演示现场最惊人的那一下 | 官方视频、现场媒体视频 |
| T3 人物企业 | 人物在公开场合的照片或影像 | 新闻图片社、维基共享资源、官方档案 |
| T4 开放科学 | 化石、标本、野外照片 | 博物馆开放藏品、维基共享资源 |
| T5 精细机构 | 真实机芯、机器在运转的特写 | 品牌资料、维基共享资源、用户提供 |
| T6 抽象过程 | 产品界面的真实使用录屏 | agent 自己录（比如录一段和大模型对话的屏幕） |
| T7 真实场景 | 产地、工厂、街头 | 图库、维基共享资源、用户提供 |
| T8 证据与边界 | 原始的科学图像或数据图 | 研究机构发布页（常为 CC BY） |
| T9 历史事件 | 档案影像 | NASA 等政府档案（多为公共领域） |
| T10 商业故事 | 产品、门店、发布会的照片 | 新闻图片、官网（不用游戏或影视角色做主画面） |

## 3. 怎么拿：agent 自己拿，按顺序试

按下面的顺序一个个试，拿到能用的就停。研究阶段可以开一个子代理专门找开场素材，任务说明里写清要哪个时刻（比如“车倒挂在坡道顶上的那一秒”）。

1. **用户给的文件。** 用户说了“我有视频”，就先用用户的。
2. **官方视频平台，用 `yt-dlp` 只下需要的那一段**：
   ```sh
   pip install yt-dlp
   yt-dlp --download-sections "*6:03-6:15" -f "bv*[height<=1080]+ba/b[height<=1080]" -o "raw/ramp.%(ext)s" "<视频地址>"
   ```
   YouTube、B 站、X、微博、官网内嵌视频都可以试。实测：在云端容器里，YouTube 经常要求人机验证（“Sign in to confirm you're not a bot”）而下载失败；在用户自己的电脑上通常能下。
3. **官方视频的封面图和截图。** YouTube 封面 `https://i.ytimg.com/vi/<视频 ID>/maxresdefault.jpg`，实测在云端容器里也能下，1280×720，往往就是视频里最有代表性的那一刻。标题和作者从 `https://www.youtube.com/oembed?url=<视频地址>&format=json` 取。封面上常有大字标题，用 `footage.sh --crop` 裁掉。
4. **新闻稿和媒体资料库**（press kit、newsroom）里的图片和视频素材。
5. **公共领域和开放授权**：NASA 素材库（`https://images-api.nasa.gov/search?q=…&media_type=video`，实测可用）、政府档案、博物馆开放藏品、维基共享资源。维基共享资源对共享出口的机器会限流（HTTP 429），隔一会儿再试，或者换来源。
6. **新闻报道里的配图和视频截帧**，标明出处。
7. **都拿不到**：用生图模型还原（第 5 节）。

几条规矩：
- 不绕过登录、付费墙和 DRM。用户自己提供登录凭据（比如 cookie 文件）时才用，不要去要。
- 真实画面尽量短：开场 3–6 秒，片中再引用时单段不超过 10 秒。它的作用是让观众认出对象，讲解仍然是代码动画。
- 每个素材都登记进 `research/assets.md`：类型、来源链接、时间码、作者、授权依据（公共领域、CC、官方素材条款，或者“引用”）、sha256、署名文字（见 `rights.md`）。
- 交付时告诉用户哪些是引用的版权素材，平台的版权识别可能会标记它们。

## 4. 处理成镜头

```sh
# 视频：截 4 秒，裁掉右下角的台标，烧上署名；同时导出最后一帧和线稿
bash scripts/footage.sh raw/ramp.mp4 scenes/_shared/opening --from 6:05 --duration 4 \
     --crop 1600:900:0:0 --credit "画面：特斯拉官方视频《The Ramp》，2026-10-16"
# 照片：只导出画面和线稿（署名由 reveal 场景画）。--cover 用黑块盖掉裁不掉的片头大字
bash scripts/footage.sh raw/ramp_thumb.jpg scenes/_shared/opening --cover 50:60:330:170 --crop 1180:664:60:56
```

输出在 `scenes/_shared/opening/`：`clip.mp4`（视频才有）、`last.png`（最后一帧）、`edges.png`（线稿）。竖版加 `--ratio 9:16`，并用 `--crop` 把主体框在中间。

`raw/` 和 `scenes/_shared/opening/` 不提交到仓库（多半是别人的版权素材），`research/assets.md` 里记着怎么重新拿到它们。

**reveal 镜头**：把 `templates/scene-reveal.html` 拷到 `scenes/<名字>/index.html`，改开头的 `REVEAL`：
- `photo`、`edges`：上面的输出；`sprite`：`scripts/anatomy/sprite.sh` 从模型抠出的贴图（2D 路线的片子用主体的 2D 画法）。
- `align`：主体在画面里的中心、宽度、角度和是否镜像。出一张 `t.model` 时刻的静帧，对着照片里的主体挪到位。照片和模型的角度不同时（照片是斜前方，模型是正侧面），线稿淡出、模型淡入的交叉能把差别盖住。
- `credit`、`badge`：署名和角标。

**分镜**：视频镜头 `"route": "R7"`、`"source": "scenes/_shared/opening/clip.mp4"`；reveal 镜头 `"route": "R7"`、`"source": "scenes/<名字>/index.html"`。两个都写 `"asset": "opening"`（在 `assets` 里登记来源），并写 `"credit"`（屏幕上的署名）。AI 还原的画面用 `"route": "R8"`。

## 5. 拿不到时：用生图模型还原

用宿主提供的生图模型（文生图或图生图都行）做一张尽量接近真实的画面，再按第 4 节处理。
- **有参考图就用图生图**：哪怕只有一张小封面或新闻截图，也比纯文字描述准。
- **提示词按“风格 → 必须有的东西 → 机位 → 不能有的东西”写**，内容全部来自事实表：
  ```
  风格：夜间活动现场的新闻摄影，高感光，冷色舞台灯，轻微运动模糊。
  必须有：一辆低矮的银白色双座跑车，车头朝下贴在一段高大的弧形混凝土坡道顶端，坡道外侧是钢桁架，
         边缘有一条红色灯带；远处有烟雾。
  机位：地面远处略仰视，坡道占画面右侧三分之二。
  不能有：任何品牌标志和文字、清晰的人脸、观众、坡道以外的建筑、来源里没有提到的动作。
  ```
- **规矩**：
  - 画面上一直挂“AI 还原画面 · 非现场影像”，分镜用 R8，素材表登记生成工具、完整提示词和参考图；
  - 不画品牌标志和文字；
  - 真实人物不生成逼真的脸：用背影、剪影、远景，或者换成插画（R6）；
  - 不添加来源里没有的细节，比如动作、地点、观众、天气；
  - 片中只用来认出对象，不当作证据。
- **没有生图模型时**：用我们的模型英雄镜头开场，配一张“新闻标题卡”：日期、事件、来源，标“示意”。

## 6. 检查

- [ ] 只看开场前 3 秒，能认出讲的是什么
- [ ] 真实画面在屏幕上的整段时间都有署名和角标；AI 还原的画面一直标着“AI 还原画面”
- [ ] 线稿和照片对得上，模型落在照片里主体的位置；reveal 的最后一帧和下一镜的第一帧对齐
- [ ] `research/assets.md` 里有这个素材的来源、时间码、授权依据和 sha256
- [ ] AI 还原的画面里没有真人的脸、没有商标、没有来源里没有的东西
